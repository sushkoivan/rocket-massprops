# Code of conduct

This project wants to be a friendly place for students, engineers and hobbyists alike.

- Be respectful and assume good intent. Critique ideas and code, never people.
- No harassment, discrimination, or personal attacks of any kind.
- Help newcomers: everyone started somewhere.
- Safety first: this project touches pressure systems and rockets. Do not encourage unsafe practice.

Unacceptable behaviour can be reported to the maintainer through a GitHub issue marked private or a direct message
on GitHub ([@sushkoivan](https://github.com/sushkoivan)). The maintainer may remove comments, commits or contributors
that break these rules.
